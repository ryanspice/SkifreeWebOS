# Original SkiFree resources

Original game and artwork by **Chris Pirih**. These 89 PNGs correspond to bitmap resources 1 through 89 in the supplied SkiFree 1.04 executable. The manifest records each resource ID, filename, byte length and SHA-256.

The conversion preserves every RGB value; exact white (255,255,255) becomes transparent and every other pixel stays opaque, matching the original white-background bitmap compositing. Nearest filtering preserves the pixel artwork. No generated replacement game artwork is used. The original executable, bitmap archive and contact sheets are excluded.

Original artwork is not covered by the platform's MIT license. The app is free and includes the resources; no user import is required.
