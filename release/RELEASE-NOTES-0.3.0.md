# SkiFreeWebOS 0.3.0 — free bundled candidate

- Includes the 28 gameplay sprite aliases; launch directly into the title screen.
- Original game/artwork credited to Chris Pirih, separately from the new MIT-licensed C++ code.
- Original Windows executable is neither bundled nor executed.
- Endless slope, immediate yeti chase, obstacles, ramps, tricks and local best distance.
- Keyboard, mouse and Magic Remote pointer/directional input paths, including clean pointer-to-key transitions.
- Native C++20/GLES2 renderer; SDL window/context/input.
- Package and source inventory/hash checks; ELF executable-permission verification.

Original timed/slalom courses, exact original physics, all NPC behavior and audio are not implemented. Consult the current verification record for actual TV and physical-input results; software input tests are not physical-controller acceptance.

Optional support links lead to Ryan's website/GitHub and a page featuring Champions of Snowboarding 2026. No payment or signup is required to play. No Homebrew listing or public release is claimed until publication occurs.
