# SkiFreeWebOS 0.4.0 — fidelity correction

Private release candidate; publication and social posts remain unsent.

The 0.3.0 prototype ran on the owner's C3, but introduced a separate chase mode, timed boost and simplified simulation. 0.4.0 replaces those with game logic adapted from the matching SkiFree 1.04 reconstruction. Ski toward the original Slalom, Tree Slalom and Freestyle starts. The yeti belongs to ordinary mountain play. Snowboarders, beginners, dogs, lift traffic and original animation/scoring routines are included.

F toggles persistent fast mode. Click/remote OK uses the original mouse jump and trick action; Insert/numpad 0/Space uses the smaller keyboard jump. Back/F3 pauses. The pause menu supplies remote access to fast mode and restart. All 89 original bitmap resources are bundled; no import or payment is needed.

The native C++/GLES platform, focus handling, pointer/key handoff, package isolation and app identity remain. The status font, TV menus and score persistence are adaptations. This is not a byte-identical-original claim.

Evidence and remaining acceptance are in `native/docs/VERIFICATION.md`. Original game/art: Chris Pirih. Reconstruction credits and rights are in `native/src/classic/PROVENANCE.md`; they are not covered by the new platform's MIT license.

No external release, repository push, Homebrew PR, social post, moderator message or ad purchase has occurred.
