# SkiFree for webOS 0.8.0

The opening lift returns to the original look without added cable lines. Its chairs remain left of Chris Pirih's credit. The original 1.04 label is playfully crossed out, with **WebOS 1.04** below and slightly right. The artwork files are unchanged; the annotation is drawn by the renderer. The package version remains 0.8.0; the intro label refers to the original game version.

Bottom instructions, the colour-button row and each button's label are centered. Click targets follow the adjusted positions.

TIME follows Original's course rules: Slalom and Tree Slalom start the clock at their entrance, exclude pause time, add the original five-second missed-gate penalties and stop at the interpolated finish. Free skiing and Freestyle do not start a new race clock. Original's controls screen now explains that distinction.

The 0.7.0 gameplay corrections and 0.6.0's accepted gentler Recreation pursuit are retained. See [verification](../native/docs/VERIFICATION.md) for timer, render, package and TV evidence. No public release or social post has been sent.
