3. Freeze one exact bundle

Match the IPK hash, source commit and release receipts before uploading files.

Use the maintainer's private handoff (outside the public source archive): IPK, source ZIP, source file manifest, notes, release manifest and checksums. The current release IPK is 3,034,062 bytes and reuses the C3-verified executable.

$repo = 'ryanspice/SkifreeWebOS'
$tag = 'v1.0.0'
$bundle = $env:SKIFREE_RELEASE_BUNDLE
if (-not $bundle) { throw 'Set SKIFREE_RELEASE_BUNDLE to the private handoff folder.' }
$ipk = Join-Path $bundle 'com.ryanspice.skifree_1.0.0_arm.ipk'
$expected = 'b0801db115564c79c84c784e234d274ca2e8b8e074b40ce6fab5c51b3eae548f'
if ((Get-FileHash $ipk -Algorithm SHA256).Hash.ToLowerInvariant() -ne $expected) {
  throw 'IPK differs from the audited candidate'
}
Get-Content (Join-Path $bundle 'RELEASE-MANIFEST.json')

Documentation-only commits can keep this binary and its evidence. Native changes need a fresh build, package audit and affected TV checks. Always regenerate the source archive after source changes.

4. Tag and publish hosting

The source repository and v1.0.0 release are public; the tag points at the final commit.

Do not move a published tag. Future releases use a new version and tag.

git show --stat v1.0.0
git ls-remote --tags origin refs/tags/v1.0.0
gh release view v1.0.0 --json isDraft,isPrerelease,tagName,url,assets
  1. Review the published tag, target, notes and assets.
  2. Use the public release as the source/download URL.
  3. Do not edit or republish 1.0.0; use a new version for changes.

A private draft would not serve public downloads; 1.0.0 is public. Source hosting and Homebrew listing remain separate actions.

5. Generate Homebrew metadata

The manifest describes one IPK; the package YAML points at the stable manifest URL.

Install the official toolbox generator if absent. Our helper accepts the current webosbrew-gen-manifest name and the older toolbox name. Keep the variables from step 3.

$minimumRelease = Read-Host 'Measured minimum starfish release'
$metadata = '.ai/outbox/homebrew-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
$releaseBase = 'https://github.com/ryanspice/SkifreeWebOS/releases/download/v1.0.0'
$manifestUrl = 'https://github.com/ryanspice/SkifreeWebOS/releases/latest/download/com.ryanspice.skifree.manifest.json'
./release/Prepare-Homebrew.ps1 `
  -IpkPath $ipk `
  -SourceUrl 'https://github.com/ryanspice/SkifreeWebOS/tree/v1.0.0' `
  -IconUrl 'https://raw.githubusercontent.com/ryanspice/SkifreeWebOS/v1.0.0/native/icon.png' `
  -IpkUrl "$releaseBase/com.ryanspice.skifree_1.0.0_arm.ipk" `
  -ManifestUrl $manifestUrl `
  -SupportPageUrl 'https://github.com/ryanspice/SkifreeWebOS/blob/v1.0.0/docs/support.md' `
  -RootRequired false -MinimumWebOSRelease $minimumRelease `
  -Pool non-free -OutputDirectory $metadata

Use compatibility evidence and /etc/starfish-release for the minimum. Firmware, SDK and marketing version numbers are different. The exact minimum is not established here.

Inspect JSON/YAML, including title, hash, size, pool and requirements. RootRequired describes the app, not how the Homebrew installer is obtained.

6. Verify published downloads

1.0.0 is published; a signed-out visitor must be able to download the manifest and its exact IPK.

  1. The package manifest is attached to the published 1.0.0 release.
  2. Do not republish or replace 1.0.0 assets.
  3. Download without account credentials and compare hash and size.
  4. Check source and support links too.
$verify = '.ai/evidence/public-download-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
New-Item -ItemType Directory -Path $verify | Out-Null
$manifestFile = Join-Path $verify 'manifest.json'
Invoke-WebRequest -Uri $manifestUrl -OutFile $manifestFile
$m = Get-Content $manifestFile -Raw | ConvertFrom-Json
$downloaded = Join-Path $verify 'download.ipk'
Invoke-WebRequest -Uri $m.ipkUrl -OutFile $downloaded
if ((Get-FileHash $downloaded -Algorithm SHA256).Hash.ToLowerInvariant() -ne $m.ipkHash.sha256) { throw 'Hash differs' }
if ((Get-Item $downloaded).Length -ne $m.ipkSize) { throw 'Size differs' }
if ($m.ipkHash.sha256 -ne $expected) { throw 'Different candidate' }

The stable releases/latest/download/ route needs a public stable latest release. Drafts and prereleases are not sufficient.

7. Submit the Homebrew listing

The PR adds one package YAML to webosbrew/apps-repo. Your IPK stays on your release host.

  1. Fork webosbrew/apps-repo and create a feature branch in a separate private checkout.
  2. Copy the generated file to packages/com.ryanspice.skifree.yml.
  3. Open a PR against webosbrew/apps-repo → main.
  4. Complete the current template with actual TV/release evidence and honest AI disclosure.
  5. Address maintainer checks and review before merge.

Do not claim full human review until it happened. A generated description, hosted release or passing CI alone does not establish listing acceptance.

8. Confirm the listing and share it

The listing appears, its download works, and its version/hash matches your release.

  • Check installation, launch and update on a supported TV. Preserve existing scores; do not uninstall the owner's game as a test.
  • Finish the Reddit, LinkedIn and X drafts with actual download/listing links and checked community rules.
  • Keep optional support links in the description.
  • For 1.1.0, keep the app ID, create a new version/tag, and regenerate the manifest at the stable URL. Review package requirements when compatibility changes.

Homebrew maintainers control listing acceptance. Announcing the app and enabling future online scores are separate steps.

Checkmarks are saved locally when available. They do not update the repository, release or acceptance evidence.
